# Arabic Support - Font library

73 extra Arabic font styles (43 families), ready to use. They are **not** installed with the mod, so the mod stays small.
The mod itself includes ten bold fonts: Cairo Bold (the default), Almarai, El Messiri, IBM Plex Sans Arabic, Mada,
Noto Kufi Arabic, Noto Sans Arabic, Rubik, Tajawal and Vazirmatn.

## How to use a font from this library

1. Download the `.fontbundle` file you want from the `Fonts` folder next to this file.
2. Put it in the mod's `Fonts` folder, next to the ten that come with the mod:
   - Steam: `steamapps/workshop/content/294100/<mod id>/Fonts/`
   - Manual install: `RimWorld/Mods/ArabicSupport/Fonts/`
3. Start the game and pick it in Options > Mod settings > Arabic Support > Font.

Tip: copy only the fonts you want. Each one is small (40 to 240 KB), but the font menu gets long with all of them.

The same `.fontbundle` files work on RimWorld 1.5, 1.6 and 1.7. On 1.7 you can also use your own plain `.ttf` or `.otf` file.

Fonts with unusually tall or deep letters can be cut off at the top or bottom of a line. If that happens, use the size and
vertical-position sliders in the mod settings, or pick another font.
