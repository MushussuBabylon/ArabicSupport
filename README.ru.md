# Мод ArabicSupport

Лёгкий мод для RimWorld, который исправляет отображение арабского текста с направлением письма справа налево (RTL), позволяет вводить арабские символы и поддерживает пользовательские шрифты.

## Возможности

- **Ввод арабского текста** — теперь вы можете вводить арабские символы непосредственно в игре (RimWorld 1.5 и 1.6, см. [Версии RimWorld](#версии-rimworld)).
- **Корректное отображение RTL** — арабские символы отображаются в правильном порядке, с правильным формированием и соединением букв.
- **Поддержка пользовательских шрифтов** — возможность заменить игровой шрифт на любой арабский шрифт по вашему выбору. По умолчанию используется **Cairo Bold**.
- **Низкая нагрузка и высокая производительность** — мод использует патчи Harmony и потребляет минимум ресурсов.
- **Перевод в комплекте** — перевод включён в загружаемый архив в виде папки `Data`, расположенной рядом с модом.

## Версии RimWorld

| RimWorld | Что работает |
|---|---|
| 1.5 и 1.6 | Всё: ввод арабского текста, отображение RTL, харакаты, пользовательские шрифты |
| 1.7 (новый движок Waylith) — экспериментально | Отображение RTL и перенос строк, расстановка харакатов, пользовательские шрифты |

**Чего нет в версии для 1.7:** исправления ввода арабского текста в текстовых полях и поиска по арабским словам. В RimWorld 1.7 вводом занимается сама игра, поэтому набранный арабский текст может отображаться с разъединёнными буквами или в обратном порядке — это зависит от нового движка.

Мод сам загружает файлы, подходящие для вашей версии игры (`LoadFolders.xml`). Заметки для разработчиков: [docs/RimWorld-1.7.md](docs/RimWorld-1.7.md).

## Установка

**Ручная установка**:

1. Скачайте последнюю версию с [GitHub](https://github.com/MushussuBabylon/RimWorld-ar) (вариант `Data-ArabicSupport`).
2. Распакуйте архив в каталог игры RimWorld. Мод будет автоматически размещён в папке `Mods`, а перевод — в папке `Data`.
3. Включите мод в игровом меню модификаций (Mods).

## Пользовательские шрифты

По умолчанию в моде используется шрифт **Cairo Bold**. Чтобы использовать другой шрифт, выполните следующие действия:

1. Перейдите в папку `ArabicSupport/ExtraFonts/Fonts` в этом репозитории.
2. Скачайте нужный файл шрифта (`.fontbundle`). (В RimWorld 1.7 также работают ваши собственные файлы шрифтов `.ttf` и `.otf`.)
3. Скопируйте скачанный файл в папку `ArabicSupport/Fonts`, заменив существующие файлы или добавив новый шрифт.
